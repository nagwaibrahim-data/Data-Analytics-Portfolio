# 🏠 Airbnb Open Data — Data Analysis

## 📌 Project Overview

This project analyzes Airbnb listing data to understand pricing, availability, reviews, host activity, and listing distribution.

The project focuses on transforming raw Airbnb data into meaningful insights through data cleaning, exploratory data analysis, and business-oriented analysis.

---

## 🎯 Business Objective

The main objective is to answer key questions such as:

- How are Airbnb listings distributed across different areas?
- How does price vary across locations and room types?
- Which room types are most common?
- Which areas have the highest number of listings?
- How does availability vary across listings?
- What patterns can be identified from reviews and host activity?
- What factors may influence listing performance?

## 📊 Analysis Areas

The analysis focuses on several important aspects of Airbnb listings:

### 💰 Pricing Analysis
Analyzing price distribution and comparing prices across different locations and room types.

### 📍 Location Analysis
Understanding how listings are distributed geographically and identifying areas with higher listing activity.

### 🏠 Room Type Analysis
Comparing the availability and distribution of different room types.

### ⭐ Reviews Analysis
Exploring review-related patterns and their relationship with listing activity.

### 📅 Availability Analysis
Analyzing listing availability throughout the year.

### 👤 Host Analysis
Examining host activity and listing distribution.

## 💡 Key Insights

The analysis is designed to help identify:

- Areas with high Airbnb listing activity.
- Differences in pricing across locations.
- The most common room types.
- Patterns in listing availability.
- Relationships between reviews and listing activity.
- Potential factors associated with listing performance.
